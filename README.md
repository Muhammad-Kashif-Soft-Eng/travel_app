# Travel Recommendation Web Application

A responsive front-end web application designed to provide travel destination recommendations based on user search queries. This project demonstrates core web development principles including DOM manipulation, asynchronous data fetching, and multi-page routing.

## Features
* **Dynamic Search System:** Fetches and filters travel destinations from a local JSON database using the Fetch API.
* **Keyword Filtering:** Users can search for specific categories such as `beach`, `temple`, or `country` to receive tailored recommendations with images and descriptions.
* **Multi-Page Architecture:** Includes fully styled Home, About Us, and Contact Us pages.
* **Interactive UI:** Features a clean navigation bar, dynamic results rendering, and functional 'Search' and 'Clear' controls.

## Technologies Used
* HTML5
* CSS3
* Vanilla JavaScript (ES6)
* JSON (Mock API)
